# 计算机视觉实验二：Fashion-MNIST

## 报告编译

需要安装 XeLaTeX（例如 TeX Live）及 `Settings.tex` 所需宏包。在此目录运行：

```bash
make
```

编译入口为 `main.tex`；提交版 PDF 位于 `output/pdf/experiment2_report.pdf`。

## 本报告所用实验配置

- 数据：Fashion-MNIST；沿用实验一的固定划分，训练集 50,000、验证集 10,000，split seed 42；官方测试集仅用于最终评价。
- 分类：训练 30 epoch，batch size 128，Adam，学习率 `1e-3`，weight decay 0；训练种子 42、123、2026。模型按验证准确率选检查点。
- 像素置换：置换种子 20261024；同一固定像素索引置换应用于训练、验证和测试图像。
- 扩散：50,000 个训练样本，基础通道数 32，100 个扩散步，30 epoch，CUDA；训练种子 42、采样种子 20261024、轨迹噪声种子 314159。固定初始噪声和采样评价张量记录在结果目录。
- 服务器记录的扩散训练时间为 129.58 秒；100 张完整采样的两份计时记录为 0.158 秒和 0.205 秒，报告按实测范围呈现。
